# 口播开头精剪（通用版）

一个给 AI 剪辑助手用的 Workflow Skill：专门剪一条单独的口播「开头」raw 原片（通常 40 秒以内），剪成 9:16 竖屏成片。标准与「口播一键成片（通用版）」完全一致，只针对开头做了专用规则。

## 它会做什么

- **粗剪**：剪试音、停顿、口癖、看稿穿帮、讲错重来，停顿压到约 0.1 秒
- **变速**：整体 1.1 倍，音高不变
- **第一帧就开口**：前面不留空白；前 3 秒内至少 1 个花字、画面至少变化 1 次
- **开场闪白 + 叮**：第 0–9 帧闪白模糊缩放入场，配 Whoosh 和 Clean Ding
- **字幕**：超粗黑体白字 + 阴影，**只能一行**，按意思断句，数字一律阿拉伯数字
- **花字**：白黄两色，按语义配动画（弹跳、砸入、金币、马克笔、翻牌、抖动等），紧贴字幕上方
- **防挡脸**：脸会被字幕或花字压到时，只放大并上移视频，字幕花字位置不动
- **画面变化**：推近 / 原尺寸交替；全屏复古撕纸 MG 最多 1 个、黑底圆框打字最多 1 处
- **音效 + BGM**：按画面事件配音效；默认 Summit Regrace BGM，人声说话时自动压低
- **全程自动**：中途不提问；剪完才问 BGM、用途（单独发布 / 接正片）、建议补哪些素材

## 文件结构

```
SKILL.md                     # 主流程、参数、判断规则、禁止事项
references/components.md     # 组件说明（属性、位置、用法）
references/mg/               # Motion Graphic 组件（Remotion JSX）
  HuaZi.jsx                  # 花字
  StrikeText.jsx             # 删除线花字
  TypeLine.jsx               # 黑底圆框段的打字字幕
  MarkerText.jsx             # 马克笔高亮字（备用）
  collage-kit.jsx            # 撕纸 MG 共用组件
  collage-*.jsx              # 7 个撕纸 MG 版式
references/effects/
  flash-zoom-in.ts           # 开场闪白入场特效
```

## 使用方式

在支持 Workflow Skill 的 AI 剪辑环境（例如 ChatCut）里导入这个 skill，然后对 AI 说"帮我剪这条开头"，附上开头原片即可。

## 说明

- 默认 BGM 通过 SKILL.md 里的公开链接下载；链接失效时不加 BGM，剪完会请你上传。
- MG 配色与字体沿用「2nd Collage｜复古撕纸」风格（新青年体 + Archivo Black，四色）。
